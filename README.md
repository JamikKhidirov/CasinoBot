# 🎮 SuperBot

Многофункциональный Telegram-бот с **казино**, **анонимным чатом** и **OSINT-сервисом**.

> 🚀 "Бот-мультимиллиардер — одна команда, бесчисленные возможности!"

```
╔════════════════════════════════════════╗
║  🎰 CASINO   |   🔍 OSINT   |   💬 CHAT   ║
╠════════════════════════════════════════╣
║  🎲 Кости     🎳 Боулинг   🎯 Дротики  ║
║  🏀 Баскетбол ⚽ Футбол   🃏 Блэкджек   ║
╚════════════════════════════════════════╝
```

## 🚀 Быстрый старт

```bash
pip install -r requirements.txt
python main.py
```

## ⚡ Особенности

### 🎰 Казино
- **PVP игры** 💰 (кости, боулинг, дротики, баскетбол, футбол)
- **Solo против бота** 🤖 (собственный баланс)
- **Блэкджек** 🃏 (турниры до 6 игроков)
- **Промокоды** 🎫 (создание/использование)
- **Топ-10 игроков** 🏆

### 💬 Анонимный чат
- Случайный подбор собеседников
- Защита от спама
- Панель модерации

### 🔍 OSINT
- **Поиск по номеру** 📞
- **Проверка email** 📧
- **Поиск username** 🌐
- **Геолокация IP** 🗺️
- **DNS-записи** 🌐

### 👑 Админ-панель
- Управление ботом
- Статистика
- Модерация

## 📋 Команды

### 🎮 Основные
- `/start` — Главное меню
- `/help` — Справка
- `/profile` — Ваш профиль
- `/top` — Топ игроков

### 🎰 Казино
- `/games` — Меню
- `/dice [ставка]` — Кости
- `/bowling [ставка]` — Боулинг
- `/darts [ставка]` — Дротики
- `/basket [ставка]` — Баскетбол
- `/football [ставка]` — Футбол
- `/blackjack [ставка]` — Блэкджек
- `/solo [игра] [ставка]` — Игра с ботом

### 🛡️ Модерация
- `/mod` — Панель
- `/ban @user` — Забанить
- `/mute @user N` — Замутить
- `/warn @user` — Предупреждение

### 🔍 OSINT
- `/phone +71234567890` — Проверка телефона
- `/email user@example.com` — Проверка email
- `/user username` — Поиск username
- `/ip 1.2.3.4` — Геолокация IP
