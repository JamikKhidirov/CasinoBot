# AGENTS.md

## Проект

Telegram-бот с режимами: **анонимный чат** (поиск собеседника, переписка, жалобы, баны, апелляции) и **Казино** (кости, боулинг, дротики, баскетбол, футбол, блэкджек, КНБ, слоты, ставки, баланс, топ).

## Запуск

```bash
python main.py
```

Бот работает на `aiogram` 3.x (асинхронный, `Dispatcher.start_polling`).

## Важные замечания

- **Токен в `config.py`** — жёстко зашит. Для продакшена вынести в переменные окружения.
- **Прокси** — если Telegram API заблокирован (ошибка `ConnectTimeout`), задайте `PROXY_URL` в `config.py` (например `"http://proxy:8080"` или `"socks5://proxy:1080"`).
- **База данных** — SQLite (`chat.db`, `casino.db`). Инициализация таблиц при первом запуске.
- **На amvera** БД сохраняются в `/data/` (persistenceMount). Локально — в корне проекта.
- **Логи** пишутся в `bot_errors.log`.
- **Ветки**: `master` и `develop`.
- **Пополнение**: администратор вводит реквизиты → пользователь оплачивает → админ подтверждает → монеты зачисляются.
- **Эмодзи-бросок**: можно отправить 🎲🏀⚽🎳🎯 в чат с ботом как бросок (помимо кнопок).
- **Футбол/баскетбол**: >3 = гол/попадание, ≤3 = промах.
- **Таймер**: на сообщении с игрой отображается обратный отсчёт 30 секунд.

## Команды бота (Telegram)

### Публичные
- `/start` — главное меню (чат + казино)
- `/help` — справка по всем командам
- `/profile` или `/профиль` — профиль игрока в казино
- `/top` или `/топ` — топ игроков
- `/games` или `/игры` — список игр казино
- `/dice [ставка]` или `/куб [ставка]` — кости
- `/bowling [ставка]` или `/боулинг [ставка]` — боулинг
- `/darts [ставка]` или `/дротики [ставка]` — дротики
- `/basket [ставка]` или `/баскетбол [ставка]` — баскетбол
- `/football [ставка]` или `/футбол [ставка]` — футбол
- `/blackjack [ставка]` или `/блекджек [ставка]` — блэкджек
- `/solo` или `/сботом` — игра с ботом (в ЛС)
- `/active` или `/активные` — активные игры
- `/unlock` или `/разблокировать` — отменить свои игры
- `/promo` — активировать промокод
- `/solotop` — топ с ботом

### Админские
- `/stats` — статистика бота
- `/admin` — админ-панель казино
- `/players` или `/игроки` — список игроков казино
- `/mod` — панель модерации
- `/ban` — забанить
- `/unban` — разбанить
- `/mute` — замутить
- `/unmute` — размутить
- `/warn` — варн
- `/check` — проверить пользователя
- `/warns` — варны пользователя
- `/chatlog` — переписка
- `/пополнить` — пополнить баланс
- `/одобрить` — одобрить депозит
- `/выводы` — запросы на вывод
- `/addbotcoins` — пополнить счёт бота
- `/createpromo` — создать промокод
- `/deletepromo` — удалить промокод
- `/promo_list` — список промокодов

## Обработка ошибок

- `is_admin()` — исправлен (двойной fetchone — баг).
- **DB-импорт**: используйте `import db` и `db.cur`, а не `from db import cur` (иначе получите `None`).
- При превышении лимита 4096 символов ответ обрезается до `[:3997] + "..."`.
